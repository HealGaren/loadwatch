# LoadWatch

내 컴퓨터의 부하를 원인별(빌드·시뮬·에뮬·세션 등)로 보여 주는 상주 앱.
새 세션이나 빌드를 더 띄워도 되는지 한눈에 판단하는 게 목적이다.

## 플랫폼

| 폴더 | 상태 | 형태 |
|---|---|---|
| [`macos/`](macos/README.md) | 사용 중 | 메뉴바 앱(Swift) + 작업 슬롯 `slot`(Python) |
| `windows/` | 예정 | 트레이 앱 |

플랫폼마다 폴더 하나에 소스·빌드 스크립트·README 를 둔다. 빌드 산출물(`build/`)은 올리지 않는다.

## 플랫폼 공통 약속

새 플랫폼도 아래를 맞추면 세션·스크립트가 같은 방식으로 판정을 읽을 수 있다.

- 등급 3단계: 여유 · 빠듯 · 과부하. 기준은 [macOS README 의 등급 표](macos/README.md#등급).
- CLI `loadwatch status` 종료 코드: 0 여유 · 1 빠듯 · 2 과부하 · 3 앱 꺼짐.
- 감시 앱 자체 부하는 최소로(외부 명령을 매번 띄우지 않고 OS API 로 직접 읽기).
